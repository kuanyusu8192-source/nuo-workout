# NUO 介面設計規範（2026-10-16）

> 依據：[[NUO新架構設計(2026-10-16)]] 第 7 題「沿用 NUO 現有色票」，並用 ui-ux-pro-max（設計系統、UX、圖表、React 規則）檢查後補強。
> 原則：**色相與模式色不變**（藍＝主色、綠＝成功、橘＝補記、紫＝出差）；只調整「文字與按鈕用的深淺」以通過對比度，並補上觸控、表單、圖表、導覽的規則。

## 1. skill 的結果與取捨

| skill 輸出 | 採用？ | 說明 |

## 2. 色票（保留色相，調整文字與按鈕深淺）

實測對比度（相對白底）：

| 現有色 | 白字對比 | 結論 | 調整 |
|---|---|---|---|
| 藍 `#3498db` | 3.15 | ✗ 小字／按鈕白字不足 | 文字與按鈕底色用 **`#2471a3`**（5.30）；`#3498db` 只用於大面積背景、圖表線、圖示 |
| 綠 `#27ae60` | 2.87 | ✗ | 按鈕底色用 **`#1e8449`**（4.72）；`#27ae60` 留給圖形與完成標記 |
| 橘 `#f39c12` | 2.19 | ✗ | 橘色底一律配**深字 `#2c3e50`**（5.01）；不使用白字 |
| 紅 `#e74c3c` | 3.82 | ✗ | 按鈕與錯誤文字用 **`#c0392b`**（5.44） |
| 紫 `#9b59b6` | 4.67 | ✓ | 不變（出差模式） |
| 深藍灰 `#2c3e50` | 10.98 | ✓ | 不變（標頭、主要文字） |

CSS 變數（`src/theme.css`）：

```css
:root {
  --ink: #2c3e50;        --ink-2: #5d6d7e;      --bg: #f0f2f5;   --card: #ffffff;
  --primary: #3498db;    --primary-600: #2471a3;
  --success: #27ae60;    --success-600: #1e8449;
  --warning: #f39c12;    --on-warning: #2c3e50;
  --danger: #e74c3c;     --danger-600: #c0392b;
  --travel: #9b59b6;     --backfill: #d35400;   /* 補記模式沿用舊版橘棕 #d35400 */
  --line: #d5dbe0;
  --radius: 14px;        --gap: 8px;
  --z-nav: 20; --z-sheet: 30; --z-modal: 40; --z-toast: 50;

```
模式色：標頭背景依模式切換（預設 `--ink`、出差 `--travel`、補記 `--backfill`），模式名稱同時用**文字標籤**顯示，不單靠顏色。

## 3. 版面與觸控

- 手機優先，基準 375 px 寬；單欄；內邊距 16 px；底部分頁列高 56 px 加安全區（`env(safe-area-inset-bottom)`）。
- 所有可點元素最小 **44×44 px**，相鄰間距 **≥ 8 px**。組數表的重量、次數輸入框高度 ≥ 48 px。
- 主要動作（儲存、完成訓練、新增一組）放在**畫面下半部**，單手拇指可達。
- 主要內容以垂直捲動為主；**避免整頁左右滑動**（拖曳排序只用把手；刪除用明確按鈕，左滑只當捷徑）。
- 內文字級 ≥ 16 px，行高 1.5；數字大標（重量、計時、容量）32 px 以上。
- 固定元素（標頭、底部分頁、浮動按鈕）不遮住內容，內容區加對應 padding。
- z-index 階層：導覽 20、面板 30、彈窗 40、提示 50。

## 4. 元件規則

| 元件 | 規則 |
|---|---|
| 組數表（Set 列） | 欄首固定標題「組／kg／次」；kg 欄 `inputmode="decimal"`，次數欄 `inputmode="numeric"`；填好後輕觸即自動存並啟動休息計時；刪除與加減組為獨立按鈕（≥ 44 px） |
| 休息計時 | 大數字 + 圓環進度；`−30s／+30s／暫停`；結束用震動＋通知；`prefers-reduced-motion` 時關閉環形動畫改數字倒數 |
| 動作卡 | 縮圖（懶載入 GIF 首幀）、名稱、星號、教學；按下顯示明確按壓回饋（顏色，不位移）；整張卡可點 |
| 動作清單 | **虛擬化**（1,324 筆）；GIF 只載可視範圍並停用離屏動畫；key 用動作 ID |
| 彈窗／面板 | 返回鍵先關面板；有標題與關閉按鈕；表單送出時按鈕停用並顯示處理中 |
| 圖示 | 全部 SVG（Lucide），固定 24×24 viewBox，`aria-label` 描述用途 |
| 空狀態 | 一句說明加一個明確按鈕（例：「今天還沒有訓練 → 開始訓練」） |
| 錯誤與驗證 | 訊息顯示在欄位旁，說明怎麼修（例：「重量需介於 0–500」） |
| 載入 | 內容區預留高度避免跳動；資料庫初始化顯示骨架畫面 |

## 5. 圖表規範

| 資料 | 圖型 | 色與標示 |
|---|---|---|
| 每日／每週／每月容量、有氧分鐘 | **長條圖** | 柱頂標數值；今天用主色，其他用淺主色；週一起排 |
| 動作 e1RM、最大重量、體重、體脂 | **折線圖**（可加 20% 透明面積） | 主色線；PR 點用綠色圓點並標示；虛線表示目標 |
| 熱量攝取 vs 目標 | 長條（攝取）＋虛線（目標） | 超標段用 `--danger-600`；同時加圖案或標籤，不只靠顏色 |
| 營養素進度 | 水平進度條 | 蛋白／碳水／脂肪各用不同形狀圖示或文字標籤，避免只靠色相 |
| 日曆 | 月曆格 | 有訓練的日子用實心點＋數字，不只靠顏色；點擊展開日摘要 |

共通：每張圖下方提供「顯示表格」切換（給無障礙與精確數值）；長按可看單點數值；圖表高度固定避免跳動。

## 6. 動態與無障礙
- 微互動 150–300 ms，只用 `transform`／`opacity`。
- 偵測 `prefers-reduced-motion`：慶祝頁的粒子與環形動畫改為靜態。
- 所有圖示按鈕有 `aria-label`；表單欄位有 `<label>`；焦點樣式可見。
- 色彩不是唯一指示（模式、PR、超標都附文字或圖示）。
- 文字對比 ≥ 4.5:1（見第 2 節，已逐色驗證）。
