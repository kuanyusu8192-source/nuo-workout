## 2. 功能清單與行為

### 2.1 主頁
- 頂部：使用教學、更新內容；模式切換「健身房訓練 / Hyrox 訓練」（Hyrox 排除，健身房為預設）。
- 「訓練項目」六大肌群入口：胸、背、臀腿、肩、手臂、核心。
- 「今日紀錄」「全年紀錄」兩個快捷入口。
- 「我的課表」（儲存並一鍵開始自訂訓練）、「新人專屬訓練計畫」、「體重追蹤」（建議每週記錄一次；按右側「記錄／歷史」開選單：新增體重紀錄／查看體重歷史）。

### 2.2 動作選擇頁（選擇訓練動作）
- 搜尋框（提示文字「想操邊個動作？例如…」，Cantonese 口吻）、器材篩選（全部、自重、啞鈴、槓鈴、壺鈴、彈力帶、繩索、器械、健身球）。
- 頂端分頁：胸、背、臀腿、肩、手臂、核心、有氧。每個分頁有「最愛」與「全部X」，並依肌肉細分（胸：上胸/中胸/下胸；肩：前束/中束/後束）。
- 動作卡：GIF/圖片、名稱、星號收藏。
- 「最愛」為空時只顯示「＋新增自訂動作」；自訂動作對話框僅有「動作名稱」一欄（取消／確認）。
- 點動作 → 對話框「加入今日訓練記錄 / 睇教學」。
  - 加入記錄 → 記錄頁（見 2.3）。
  - 睇教學 → 動作詳情（四分頁：教學、紀錄、圖表、歷史）。

### 2.3 重訓記錄頁（核心）
- 欄位：日期（可改，預設今天）、組數表（組數／重量 kg／次數），「＋新增一組」，「儲存記錄」。
- 組間休息計時器：預設 01:00，±30 秒，播放鍵；**填入重量與次數後計時器自動開始倒數**（實測 01:00 → 00:55 → 00:27）。預設秒數可設定（`defaultRestTimerSeconds`）。
- 鍵盤上方「完成」按鈕收起鍵盤。
- 右上：歷史紀錄、動作教學。
- 預填：開啟動作時以上次紀錄預填（`applyLastSessionPrefill`）；草稿暫存（`exerciseSetDraftPrefsKey`）。
- 單位：kg／lb 切換（`isWorkoutLbs`、`kgToDisplayWeight`、`displayWeightToKg1`），內部以 kg 儲存。
- **儲存後**：跳出慶祝頁（見 2.6），然後回到動作選擇頁。

### 2.4 有氧記錄頁
- `cardioTrackingType` 決定欄位：跑步 → 時間（分鐘）、速度、斜度；其他型別另有距離、配速（每 500 公尺，划船機）、功率（瓦）、樓層（爬梯）、伸展為最長秒數。無組間休息。
- 有氧約 30 個動作（波比跳、划船機、固定自行車、橢圓機、跑步機、跑步等），另有「overlay」型動作（如划船機）使用預設圖。

### 2.5 動作詳情（四分頁）
- 教學：動作名、教學影片、肌肉部位（主／副）、「詳細訓練要點」分步驟文字與教練提示。
- 紀錄：同 2.3。
- 圖表：期間（3 個月／1 年／全部）；四張圖：力量突破（e1RM）、總訓練容量、最大次數、總訓練次數；無資料時顯示「暫無此動作之訓練數據，完成一次訓練即可顯示趨勢」。
- 歷史：個人紀錄（最大次數、最大重量、最高總容量）與「檢視紀錄歷程」。

### 2.6 慶祝頁（`workout_celebration_dialog`）
- 新高（PR）時：橘色橫幅「恭喜打破 PR！」＋「<動作> 新高：40 kg」；中央圓形徽章 emoji。
- 「容量提升！ 0 → 400 / 10,000 kg」＋進度條：**累積總容量朝下一個里程碑（實測 10,000 kg）推進**；有氧存檔時顯示 400 → 400（不增加）。
- 點任意處繼續。

### 2.7 今日紀錄
- 入口彈窗「新增動作 / 查看紀錄」。
- 視窗：今日訓練紀錄，總容量（kg）＋消耗（kcal），每個動作列出組數／重量／次數，每組有「編輯組數」「刪除組數」（**刪除無二次確認**），有分享按鈕（`workout_share_screen`，產生訓練分享圖）。
- 無資料：「今日尚未有訓練紀錄」。

### 2.8 全年紀錄（日曆）
- 指標：連續訓練週數、本月訓練天數、本月總消耗 kcal。
- 月曆：有訓練的日子標🔥；點日期顯示摘要卡：日期／肌群（肩部、核心）／動作數·總組數·容量／總時長（分鐘）／kcal／「查看詳情」。
- 免費版只顯示最近 7 天（付費牆：`filterHistoryRecordsForTier`、`historyDayRequiresPaywall`）。

### 2.9 歷史（底部分頁）
- **統計**：本週熱量趨勢（攝取 vs 每日目標，1 週免費，1 個月與 1 年需 Pro），指標切換：熱量／蛋白質／碳水／脂肪（水分排除）；目前體重、目前體脂。
- **紀錄**：gym／Hyrox 切換（Hyrox 排除）；總訓練容量柱狀圖（週免費，月、年需 Pro）；子切換「重訓 (kg) / 有氧 (分鐘)」；「力量突破」卡：預估 1RM、動作下拉選單、最佳訓練組數紀錄（含「新高」標籤，資料不足時提示「再記錄一次即可顯示趨勢」）。

### 2.10 課表範本與新人計畫
- 我的課表：清單（名稱、動作數、建立時間）、複製、刪除、「建立課表」；數量上限標示 `3 / 6`（免費上限 6）。範本可複製為「名稱 (複製)」。
- 新人專屬訓練計畫：選每週日數（2／3／4／5 日）→ 自動配對分化（例 3 日＝推／拉／腿）、性別（男／女）、「新手安全模式（器械為主）」；顯示每個訓練日的動作與組次（如 3 組 × 10–12 次、約 45 分鐘）。

### 2.11 食物分析（僅保留手動輸入）
- 日期條（本週七天，🔥/💪 標記該日有記錄）、每日熱量目標（例 1870 kcal，可「重新計算」）、剩餘可攝取、蛋白質／碳水／脂肪進度條（目標克數由目標熱量與配比推得）。
- 「＋記錄飲食」「記錄運動消耗」。
- 排除：AI 菜單、飲水、條碼、食物搜尋。保留 `manual_food_entry_sheet`、`meal_portion_picker_sheet`、`edit_meal_*`、`favorite_meal_*`、`meal_history_*`、`diet_logged_calendar_dialog`。

### 2.12 記錄運動消耗
- 手動輸入消耗 kcal（留空並儲存恢復自動計算），可選日期；預設由訓練容量自動估算；Android 可由 Health Connect 同步穿戴資料。
- 開關「將運動消耗計入每日可用熱量」：關閉後僅作紀錄、不增加剩餘可攝取卡路里。

### 2.13 匯入
- Hevy CSV、Strong CSV 匯入（`importHevyWorkouts`、`importStrongWorkouts`、`parseHevyCsvRows`、`parseStrongCsvRows`、`csv_exercise_resolver` 以名稱對應動作庫）。

### 2.14 其他
- 通知排程（`initializeNotificationSchedule`、`createNotificationChannel`）、螢幕常亮（wakelock）、震動、語言（zh-TW、zh、en 等）、主題。

## 4. 實驗確認的算式與數據點

| 項目 | 結果 |
|---|---|
| e1RM | **Epley**：40 kg × 10 次 → 53.3 kg ＝ 40×(1+10/30) |
| 單日總容量 | Σ（重量 × 次數）：40×10 ＝ 400 kg |
| 容量里程碑 | 進度條分母 10,000 kg（更高里程碑未觀察） |
| PR 判定 | 首次記錄該動作即視為新高（最大重量與容量皆為新高） |
| 重訓消耗 | 1 組、約 3 分鐘 → 17 kcal |
| 跑步消耗 | 20 分鐘、速度 8、斜度 1 → 133 kcal（單日合計 150） |
| 單日時長 | 重訓 3 分 ＋ 有氧 20 分 ＝ 23 分（重訓時長的算法未確認，可能為首末筆時間差或組數估算） |
| 休息計時 | 填入組資料後自動開始，預設 60 秒 |

> 卡路里推導缺體重基準（體重欄為「--」），僅能確定為 MET×體重×時間型（`workout_met_calorie_calculator`），有「按組數推估」後備（`fallbackCaloriesFromSets`）。NUO 可自訂 MET 表。

- 預設營養分配（由實際數值反推）：目標 1870 kcal → 蛋白質 164 g（約 35%）、碳水 117 g（約 25%）、脂肪 83 g（約 40%）。

### 8.7 第三輪補充（體重、TDEE 第三步、完成訓練）
- **體重歷史**：從主頁「體重追蹤 → 記錄／歷史 → 查看體重歷史」開啟底部面板「體重變化歷史」；無資料時顯示「暫無體重紀錄，請先記錄您的第一次體重！」。因不新增體重資料，圖表本身未見到（NUO 自行設計：折線圖＋最近值＋變化量）。
- **TDEE 第三步（目標）**：減脂（熱量赤字，約低於 TDEE 20%）、維持體重（= TDEE）、增肌（熱量盈餘，約高於 TDEE 10%）；按「完成」才儲存，新目標熱量再依 8.2 的 35/25/40 分配營養素。
  公式整理：BMR（Mifflin–St Jeor）× PAL → TDEE；目標熱量 = TDEE × (0.8 | 1.0 | 1.1)。
- **完成訓練（空訓練）**：進行中訓練不輸入任何組直接按「完成訓練」→ 底部按鈕變成「🎉 訓練完成」（已完成狀態）、整場計時器停止（實測停在 05:27），**不會產生任何紀錄**（今日紀錄、全年紀錄皆無變化）。
- 進行中訓練各組欄位平時以灰字顯示 kg／reps，不會自動填值。
- 有輸入組數時的完成流程（逐動作寫入、慶祝頁、PR 判定）依 2.3／2.6 推論相同，未再實測以免寫入資料。
