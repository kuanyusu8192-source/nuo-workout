## P1 domain 純函式（先寫測試）

目錄 `src/domain/`，每個檔案配 `*.test.ts`。原則：不依賴 DOM 與資料庫。

### Task 1.1 e1RM 與容量（`strength.ts`）
- 測試先行：
  - `e1rm(40, 10) ≈ 53.33`、`e1rm(100, 1) === 100`、`e1rm(0, 10) === 0`。
  - `volume([{w:40,r:10}]) === 400`。
- 實作：Epley；reps ≤ 1 回傳重量。

### Task 1.2 PR 判定（`pr.ts`）
- 測試：首次紀錄必為 PR；後續較輕不是 PR；e1RM 更高（重量低但次數多）為 PR；容量更高為 PR。
- 回傳哪一種新高（`weight|e1rm|volume`）。

### Task 1.3 統計聚合（`stats.ts`）
- 函式：`dailyVolume(sets)`、`weekBars(sets, weekStart)`、`monthBars`、`yearBars`、`cardioMinutesBars`、`trainingDays(sets, month)`、`streakWeeks(sets, today)`。
- 測試：空陣列歸零；跨週界線；刪除最後一組後 `trainingDays`、`streakWeeks` 為 0（避開原版殘留問題的迴歸測試）。

### Task 1.4 TDEE 與營養（`nutrition.ts`）
- 測試（使用已實測數據）：目標 1870 → 蛋白 164 g、碳水 117 g、脂肪 83 g（四捨五入）；`kcalFromMacros(164,117,83) === 1871`；PAL 係數表；目標倍率 0.8／1.0／1.1。
- 實作：Mifflin–St Jeor（男／女；「其他」取兩者平均）。

### Task 1.5 消耗估算（`burn.ts`）
- 測試：`burn({met:5, kg:70, minutes:60}) === 350`；ACSM 跑步（8 km/h、坡度 1%）回傳合理 MET 範圍；無體重回傳 `null`；手動覆寫優先。
- 實作：重訓 MET 可設定；其他有氧查表；時間規則（計時器優先，否則每組 3 分鐘）。

### Task 1.6 週計畫與日期（`plan.ts`、`dates.ts`）
- 測試：`todayTemplateId(plan, date)` 依星期取課表；週一為一週起點；本地日期字串 `YYYY-MM-DD`。

### Task 1.7 匯入解析（`import-csv.ts`）
- 測試用最小樣本 CSV（Hevy、Strong 各一個，自行編寫，不用個人資料）。
- 實作：解析成中介格式（日期、動作名稱、重量、次數、單位）；動作名稱對應交給 resolver（P6 完成）。

驗收：`npm test` 全綠、覆蓋率報告列出 domain 層 ≥ 90%。

## P4 整合

依「使用者流程」逐條串通，每條一個 Task，並各寫一個整合測試（fake-indexeddb ＋ Preact Testing Library）：

1. **4.1** 首次問卷 → 寫入 profile、算出 TDEE 與營養目標。
2. **4.2** 週計畫 → 首頁顯示今日課表 → 一鍵開始 → 建立今日 session。
3. **4.3** 今日訓練 → 每組填完即寫入 `sets`、自動開始休息計時 → 最後一組觸發 PR 判定與慶祝頁。
4. **4.4** 今日紀錄 → 編輯、刪除組 → 統計即時更新（迴歸測試：刪光後連續週數、訓練天數為 0）。
5. **4.5** 歷史 → 柱狀圖、動作圖表、日曆、日摘要卡、本月 kcal。
6. **4.6** 運動消耗 → 自動估算、手動覆寫、開關影響剩餘熱量。
7. **4.7** 飲食 → 手動輸入（每 100g 與份數）、營養進度、最愛、飲食日曆。
8. **4.8** 體重與體脂 → 歷史折線圖、更新用於消耗估算的體重。
9. **4.9** 備份 → 匯出分享、匯入還原。
10. **4.10** 補記模式（日期切換）與出差模式切換（紫／橘模式色）。

**CP3：** 手機上實跑完整流程並錄下問題清單。
